# Luna-js

Luna.js — a modern bridge between server-driven applications and Telegram Mini Apps, inspired by the simplicity and elegance of Inertia.js.

## Contributing

The Luna contributing guide can be found in the [LaraGram documentation](https://laraxgram.github.io/contributions.html).

## Code of Conduct

The LaraGram Code of Conduct can be found in the [LaraGram documentation](https://laraxgram.github.io/contributions.html#code-of-conduct).
